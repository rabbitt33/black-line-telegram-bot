
# 💈 BLACK LINE — Telegram Booking Bot

Telegram-бот для записи клиентов в барбершоп.

## Возможности

- Просмотр услуг и цен
- Выбор даты и свободного времени
- Создание записи с подтверждением
- Просмотр и отмена собственных записей
- Уведомления администратора о новых записях
- Просмотр всех записей через команду `/bookings`
- Статистика через команду `/stats`
- Хранение записей в SQLite
- Приветственный баннер

## Установка

1. Установите Python 3.13.
2. Скачайте или клонируйте проект.
3. Установите зависимости:

   ```bash
   py -3.13 -m pip install -r requirements.txt
   ```

4. Создайте файл `.env` рядом с `main.py`.
5. Добавьте в `.env` токен Telegram-бота:

   ```dotenv
   BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
   ```

6. Запустите бота:

   ```bash
   py -3.13 main.py
   ```

## Команды администратора

- `/bookings` — список записей
- `/stats` — статистика
- `/admin` — справка

## Безопасность

Не публикуйте `.env` и не передавайте токен бота третьим лицам.
